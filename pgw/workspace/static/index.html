          How it works

          1. Your request goes to the privacy gateway, never straight to an AI

            The workspace has no route to any AI service. Everything passes through the company's privacy gateway, which applies a signed data contract for each task.

          2. Personal details are replaced before anything leaves

            Names, employee IDs, contact details and pay are swapped for placeholders such as [PERSON_7K2Q9D]. Government and bank numbers are removed entirely. People you list under “People in this request” are protected wherever they appear.

          3. Pasted text stays inside the company

            Text you paste is not signed by an approved source system, so the gateway sends it only to the in-house model. Only text signed by an approved source (for example a helpdesk export) may go to an external AI, protected.

          4. Forms are computed inside the gateway

            For salary, ESI and pay-band tasks you fill typed fields. The gateway computes the result itself; the external AI sees only placeholders and the computed facts, never the exact pay.

          5. A final check, then the real details come back

            Before sending, the gateway checks the exact outgoing text for every value it found or you declared, and stops the request if any is present. When the answer returns, placeholders are turned back into the real details for you.

          Limits: the gateway finds identifiers, not sensitive topics such as health or disciplinary details. The checks shown after each run describe exactly what was verified for that request.
